记一场牌局
选人上场时每人自动记一笔这个金额。留空则不加买入。
买入 = 往牌桌上放的本金（上桌带的钱、中途再加的筹码，都是买入，性质完全一样）。 每次填新金额后按 回车 或点 +，就记一笔进明细 —— 结余不受影响， 所以「这些钱是本金」这件事不会被算成输赢。
「盈亏」= 结余 − 总买入，随输入实时更新。结余由你自己填（离桌时手里还剩多少）， 中途加过筹码就自己改成加完之后的数。买入格右上角的数字角标是已买笔数，点它可查看/撤销每一笔。
上面设了本局买入的话，选人上场时每人会自动记一笔这个金额，省得逐个填。

数据备份与恢复
JSON 备份包含全部账本、人员与牌局记录，用于完整恢复。
Excel 明细是当前账本的逐局流水（人员 / 买入 / 总买入 / 结余 / 盈亏）， 金额保留两位小数，方便对账。
恢复会覆盖当前设备上的全部数据，建议先导出一份当前数据再恢复。
